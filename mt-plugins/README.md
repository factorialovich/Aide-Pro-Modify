# Плагины MT Manager — factorialovich

Каталог для R91 и следующих сборок мода на базе R85. Встроенная копия 61 плагина работает без аккаунта MT и сети. Обновления приложение читает из `catalog.json` этого репозитория по HTTPS. Это отдельный каталог пользователя, поиск сторонних репозиториев отключён.

## Добавить или обновить плагин

1. Загрузите готовый `.mtp` в `mt-plugins/incoming/` через GitHub.
2. Workflow **MT plugin catalog** проверит пакет, присвоит имя `plugin.id-versionCode.mtp` и обновит каталог, SHA-256, размер, название, описание и значок.
3. В приложении обновите список центра плагинов. Новые версии появятся без переустановки APK; без сети останется встроенный или последний сохранённый каталог.

Для обновления увеличивайте `versionCode` в manifest.json. Старые версии в `files/` сохраняются и доступны через историю. Уже опубликованную версию заменять другим содержимым запрещено. Для удаления версии удалите её `.mtp` из `files/` — workflow обновит список.

Пакеты только с исходниками сначала соберите в локальном центре разработки и загрузите полученный MTP из `build/`. В стартовом наборе 8 пакетов с исходниками уже собраны; исходники и ресурсы сохранены. Два плагина имеют только настройки и корректно не содержат внешних интерфейсов.

Для ручного обновления: `python3 -m pip install json5==0.12.1`, затем `python3 mt-plugins/tools/update_catalog.py`. Если Actions отключены в настройках GitHub, используйте этот способ и загрузите изменённый каталог.

Ключи сторонних переводчиков и AI-сервисов пользователь вводит в настройках самих плагинов. Они не являются аккаунтом MT. Названия внутренних pluginID и классов сохранены для совместимости настроек и обновлений.
